Die Web-Oberflaeche fehlt. Die Firmware laeuft, aber in der LittleFS-Partition storage liegt keine index.html.

Das ist der erwartete Zustand nach einem frischen Flash oder nach dem Wechsel der Partition von SPIFFS auf LittleFS. Die Assets werden getrennt von der Firmware geschrieben:

pio run -t buildfs
pio run -t uploadfs

Die API ist davon unabhaengig und funktioniert bereits: /api/status
